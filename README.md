# 🎯 Арена 3D

Бесплатная 3D королевская битва на 100 игроков прямо в браузере.

**▶ Играть:** https://tarasula.github.io/arena-3d/

Прыгай из летающего автобуса, собирай оружие и сундуки, угоняй машины, катайся по тросам и стань последним выжившим. За победы получай 👑 короны и покупай скины и суперкары.

- Работает на компьютере, телефоне и планшете, ничего не нужно устанавливать.
- Вся графика, звуки и музыка создаются кодом: игра весит около 250 КБ.
- Прогресс (короны, скины, 3D-пасс) сохраняется в браузере.

## Управление

**W A D**: ходить · **↓**: назад · **S**: присесть · **Shift**: бег · **Пробел**: прыжок · **Мышь**: стрелять · **ПКМ**: прицел · **1–9 / Q / колёсико**: оружие · **R**: перезарядка · **E**: дверь, машина, продавец, трос · **G**: граната · **H**: аптечка · **I**: инвентарь · **Enter**: чат

На телефоне: левая половина экрана работает как джойстик, правая как камера, остальное на кнопках.

## Технологии

Один файл `index.html` и [Three.js r128](https://threejs.org/).
